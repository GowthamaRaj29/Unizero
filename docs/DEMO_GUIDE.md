# Demo Guide

## Start

From the repository root on Windows:

```bat
start-Unizero.bat
```

Open `http://127.0.0.1:5173`.

## Current Verified Path

1. Register the first account; it becomes the active admin.
2. Register another investigator or approver; it remains pending.
3. Log in as admin and open Registration Approvals.
4. Approve or reject the database-backed request.
5. Log in as an approved investigator.
6. Create a workflow.
7. Select two CSV/XLSX/JSON/XML files and ingest them.
8. Review validation findings and use Go Ahead where required.
9. Open Field Mapping and validate the AI mapping.
10. Open Breaks and Investigation when a real break has been generated.
11. Use the approver account for submitted investigations.

The final steps from a real reconciliation run through report verification are not yet certified. Do not present them as a complete acceptance demo until `FINAL_VALIDATION_REPORT.md` is updated with executed evidence.
